# PyToolkit

A CLI toolkit of everyday automation utilities built with Python.

## Features
- File Organizer
- Bulk Renamer
- Duplicate Finder
- PDF Merger/Splitter

## Usage
```
python cli.py organize <folder_path>
python cli.py rename <folder_path> --prefix vacation_ --dry-run
python cli.py duplicates <folder_path> --delete
python cli.py merge file1.pdf file2.pdf --output merged.pdf
```
